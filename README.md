# 🎰 THE LUCKY ARCADE EN JAVA 🖥️ 🎲

Este proyecto tiene como objetivo desarrollar e implementar un juego de tragamonedas interactivo utilizando el lenguaje de programación Java, aplicando conceptos fundamentales de lógica de programación, manejo de archivos y programación estructurada.

A través de este trabajo, se busca comprender cómo interactuar con el usuario mediante consola, gestionar apuestas, controlar saldos y almacenar información persistente de jugadores utilizando archivos .csv.

Además, el proyecto implementa mecánicas dinámicas como animaciones en consola, generación aleatoria de símbolos, sistema de premios y ranking de jugadores, ofreciendo una experiencia más completa e interactiva.

También se utilizan estructuras de datos, validaciones y métodos organizados para garantizar un funcionamiento correcto y una mejor organización del código.

En resumen, este proyecto demuestra cómo desarrollar una aplicación de consola en Java capaz de manejar datos persistentes, lógica de videojuegos básicos y simulaciones visuales mediante ASCII Art.

⸻

## ⚙️ ¿Qué se aprende en este proyecto?

* Uso de variables y estructuras de control
* Manejo de Arrays y ArrayList en Java
* Uso de Scanner para entrada de datos
* Lectura y escritura de archivos .csv
* Manejo de archivos con BufferedReader y BufferedWriter
* Uso de FileReader y FileWriter
* Generación aleatoria con Math.random()
* Validación de datos ingresados por el usuario
* Uso de métodos para organizar el código
* Manipulación de matrices bidimensionales
* Implementación de lógica de apuestas y premios
* Ordenamiento de datos para ranking
* Animaciones en consola usando Thread.sleep()
* Representación gráfica mediante ASCII Art
* Desarrollo de programas interactivos en Java
